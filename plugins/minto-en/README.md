# Minto (English)

A Claude skill based on Barbara Minto's Pyramid Principle. It organizes your ideas with the conclusion first and supporting arguments grouped logically. It has four modes: clarify what you want to say, structure a text from scratch or from your notes, review a draft without rewriting it unless you ask, and define a problem before a proposal. It works for emails, proposals, reports, presentations, academic writing and teaching. It responds in the language of your text.

Installation, examples and credits are in the [main README](../../README.en.md).

Install in Claude Code:

```bash
claude plugin install minto-en --marketplace cesarduartef/minto
```
