# Patrones de documentos frecuentes

Minto observa que la mayoría de los documentos de negocio responden unas pocas preguntas repetidas. Para cada tipo, aquí está la SCQ en esqueleto, cómo suele verse con contenido y la línea clave que normalmente la sigue. Son puntos de partida: si el material pide otra estructura, manda el material.

En casi todos, la pregunta queda implícita en el texto, pero hay que escribirla para uno mismo antes de redactar.

## 1. Pedir que alguien haga algo (dar una instrucción)

Aquí la introducción no le recuerda al lector una pregunta: se la siembra.

```
S = Queremos lograr X
C = Para eso necesitamos que hagas Y
P = (¿Cómo hago Y?)
R = Pasos, cada uno con fecha y resultado
```

Cuando la pregunta es "¿cómo?", la respuesta casi siempre son pasos en orden temporal. La complicación y la respuesta suelen ser una inversa de la otra: la respuesta es el efecto de ejecutar los pasos.

Variante para procedimientos: S = haces X; C = hay que hacerlo de una manera específica; P = (¿cuál es esa manera?).

## 2. Pedir aprobación para un gasto o inversión

La pregunta del lector siempre es "¿debo aprobarlo?".

```
S = Tenemos un problema (descrito con datos)
C = Hay una solución que cuesta N
P = (¿Debo aprobarla?)
R = Te pido aprobarla
```

Línea clave habitual, en este orden:
1. El problema no puede esperar.
2. Esta acción lo resuelve (o es la mejor forma de resolverlo, si hubo alternativas).
3. El costo se compensa con el ahorro o el retorno esperado.
4. Beneficios adicionales, solo si los datos los sostienen. Si no, se omite.

El punto 1 permite contar el problema en detalle; el 2, la solución; el 3, el análisis financiero.

El costo por sí solo no es una razón para aprobar: va en la idea principal ("te pido aprobar X, que cuesta N") o dentro del punto 3. Si no hay datos para mostrar que se compensa, el punto 3 queda como `[falta dato: ...]` y no se afirma.

## 3. Explicar cómo hacer algo

```
S = Queremos o necesitamos hacer X
C = No sabemos cómo, o lo estamos haciendo mal
P = (¿Cómo lo hacemos?)
R = Pasos o cambios, escritos como resultados
```

Sirve tanto para algo que el lector nunca hizo como para algo que ya hace y debe hacer mejor.

## 4. Elegir entre alternativas

Minto advierte que, si el problema está bien definido, en rigor no hay "soluciones alternativas": algo lo resuelve o no lo resuelve. Un documento de alternativas tiene sentido cuando el lector ya conoce las opciones porque se discutieron antes.

```
S = Queremos lograr X
C = Hay varias formas de hacerlo: A, B y C
P = ¿Cuál conviene más?
R = Conviene B
```

Línea clave preferida: organizada por los **criterios** que se usaron para decidir (costo, plazo, riesgo...), mostrando cómo B gana en cada uno. Si eso no se puede, por las razones por las que cada alternativa descartada falla.

## 5. Propuesta a un cliente nuevo

```
S = Tienen un problema (una o dos oraciones)
C = Decidieron buscar ayuda externa para resolverlo
P = (¿Son ustedes los indicados?)
R = Sí
```

Línea clave habitual:
1. Entendemos el problema.
2. Tenemos un enfoque sólido para resolverlo.
3. Tenemos experiencia aplicando ese enfoque.
4. Las condiciones comerciales tienen sentido.

Se usa cuando conviene dedicar espacio a explicar el problema, porque al hacerlo se demuestra conocimiento. En el texto, la complicación y la pregunta suelen quedar implícitas: "Nos dio gusto conversar sobre [problema]. Este documento presenta cómo proponemos ayudarlos a [resultado deseado]".

## 6. Propuesta a un cliente conocido o cuando la propuesta es un trámite

```
S = Tienen un problema (explicado en tres o cuatro párrafos)
C = Quieren ayuda para resolverlo
P = ¿Cómo nos ayudarían?
R = El enfoque
```

El cuerpo se organiza alrededor del enfoque, porque sobre eso decide el cliente. La experiencia se teje dentro de la explicación del enfoque, no en una sección aparte. Las condiciones comerciales pueden ir en una carta o sección separada.

## 7. Informe de avance

El primero:
```
S = Estamos trabajando en el problema X
C = Dijimos que el primer paso era averiguar si Y. Ya lo hicimos
P = (¿Qué encontraron?)
R = El hallazgo
```

Los siguientes:
```
S = En la revisión anterior les dijimos X
C = Ustedes nos pidieron investigar Y, y ya lo hicimos
P = (¿Qué encontraron?)
R = El hallazgo
```

La respuesta abre con lo encontrado, no con lo que se hizo para encontrarlo.

## Correspondencia con la pregunta del lector

| Pregunta | Patrón |
|---|---|
| ¿Qué debo hacer? / ¿Cómo lo hago? | 1 o 3 |
| ¿Debo aprobarlo? | 2 |
| ¿Cuál elegimos? | 4 |
| ¿Son los indicados? / ¿Cómo nos ayudarían? | 5 o 6 |
| ¿Qué encontraron? | 7 |
