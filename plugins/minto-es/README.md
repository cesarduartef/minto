# Minto (español)

Skill para Claude basada en el Principio de la Pirámide de Barbara Minto. Ordena tus ideas con la conclusión primero y los argumentos agrupados con lógica. Tiene cuatro modos: aclarar lo que quieres decir, estructurar un texto desde cero o desde tus notas, revisar un borrador sin reescribirlo sin permiso, y definir un problema antes de una propuesta. Sirve para correos, propuestas, informes, presentaciones, textos académicos y clases. Responde en el idioma de tu texto.

Instalación, ejemplos y créditos en el [README principal](../../README.md).

Instalación en Claude Code:

```bash
claude plugin install minto-es --marketplace cesarduartef/minto
```
